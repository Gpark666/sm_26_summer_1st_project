# DL Train

객체 탐지 성능 고도화를 위한 데이터 준비, 모델 학습, 평가 실험을 관리하는 워크스페이스입니다.

## AI Server와의 역할 분리

- `AI-server`: 검증된 모델을 로드해 실시간 또는 준실시간으로 추론합니다.
- `DL-Train`: 데이터셋을 준비하고 모델을 학습·평가해 배포 후보 모델을 만듭니다.

학습이 완료된 모델은 검증 절차를 거쳐 `AI-server`의 배포용 모델로 전달합니다. 학습 코드가 추론 서비스에 섞이지 않도록 두 영역을 분리합니다.

## 예정 디렉토리 구조

```text
DL-Train/
├── datasets/          # 원본/가공 데이터셋 (Git 제외)
├── annotations/       # 라벨 및 데이터셋 정의 (민감 데이터는 Git 제외)
├── configs/           # 학습·평가 설정
├── notebooks/         # 탐색·분석 노트북
├── scripts/           # 변환, 학습, 평가, 내보내기 스크립트
├── runs/              # 실험 결과·체크포인트 (Git 제외)
└── models/            # 배포 후보 모델 (대용량 파일은 Git 제외)
```

## 권장 흐름

```text
영상 수집 -> 라벨링 -> 데이터 검증 -> 학습 -> 평가 -> 모델 내보내기
                                                    ↓
                                              AI-server 배포 검증
```

## 관리 원칙

- 데이터셋의 출처, 수집 기간, 라벨 규칙, 사용 권한을 기록합니다.
- 학습 실행마다 데이터셋 버전, 모델 설정, 지표(mAP·precision·recall), 모델 해시를 남깁니다.
- 원본 영상, 개인정보가 포함된 데이터, 대형 체크포인트는 Git에 커밋하지 않습니다.
- 운영 적용 전 AI-server의 테스트 영상으로 처리 FPS와 탐지 품질을 함께 검증합니다.
